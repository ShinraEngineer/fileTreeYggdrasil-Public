# FileTree Yggdrasil

A fast Windows disk-space analyzer — direct NTFS **MFT scanning**, a treemap view, and an
Explorer-style breakdown, with a dark UI. Finds what's eating your drive in seconds.

## Download

**[⬇ Download the latest release](https://github.com/ShinraEngineer/fileTreeYggdrasil-Public/releases/latest)**

- Windows 10 / 11, 64-bit
- Self-contained — no .NET install needed
- Signed by **Shinra CC**
- Portable: runs from the folder; `Data\` is written beside it

## Features

- Direct **MFT scan** for speed (reads the NTFS Master File Table, not a slow recursive walk)
- **Treemap** + per-folder size breakdown
- Hard-link / symlink / junction–aware sizing (no double-counting)
- Dark, keyboard-friendly UI
- **In-app updates** — checks this repo's release feed and installs the newer signed build

This is the public download + release feed. The source is private.
